# Decisioni

Una decisione per file, numerata, in ordine di adozione. Sono decisioni
**prese**: chi arriva dopo le applica, non le ridiscute. Se una va cambiata, si
scrive un file nuovo che dichiara di sostituire il vecchio, e il vecchio resta
li' a raccontare perche' era stata presa.

Servono a questo: quasi ognuna di queste e' costata un errore in produzione o
una correzione dell'utente. Rileggerle costa qualche minuto; riscoprirle da capo
e' costato giorni.
